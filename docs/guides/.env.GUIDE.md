# 📝 Quick Guide: Using the Consolidated .env File

## 🚀 Quick Start

### Load Environment Variables
```bash
source .env
```

### Verify Configuration
```bash
echo $AUTH0_ADMIN_TOKEN
echo $DB_HOST
```

---

## 🔑 Key Variables

### Authentication Tokens
```bash
AUTH0_ADMIN_TOKEN=<full_admin_access>
AUTH0_USER_TOKEN=<basic_user_access>
AUTH0_MACHINE_TOKEN=<service_to_service>

# Legacy aliases (also supported)
ADMIN_TOKEN=<same_as_AUTH0_ADMIN_TOKEN>
USER_TOKEN=<same_as_AUTH0_USER_TOKEN>
```

### Database
```bash
DB_HOST=postgres
DB_PORT=5432
DB_NAME=cineca_platform
DB_USER=cineca_user
DB_PASSWORD=change_me_now
```

### Auth0 Configuration
```bash
AUTH0_DOMAIN=cineca.eu.auth0.com
AUTH0_CLIENT_ID=<your_client_id>
AUTH0_CLIENT_SECRET=<your_secret>
AUTH0_AUDIENCE=api://cineca-agentic-platform
```

---

## 🔄 Common Tasks

### Generate Fresh Tokens
```bash
./fetch_auth0_tokens.sh --save-to-env
```

### Test API with Tokens
```bash
source .env
curl -H "Authorization: Bearer $AUTH0_ADMIN_TOKEN" \
  http://localhost:8000/v1/user/me
```

### Run Tests
```bash
source .env
pytest tests/
```

### Start Services
```bash
docker-compose up -d
```

---

## ⚠️ Important Notes

1. **Never commit `.env`** - It contains secrets!
2. **Use `.env.example`** as a template for new setups
3. **Tokens expire** - Regenerate periodically
4. **Both variable names work:**
   - `AUTH0_ADMIN_TOKEN` (recommended)
   - `ADMIN_TOKEN` (legacy, still supported)

---

## 🆘 Troubleshooting

### Token Expired
```bash
# Regenerate tokens
./fetch_auth0_tokens.sh --save-to-env
source .env
```

### Missing Variables
```bash
# Check what's loaded
env | grep AUTH0
env | grep DB_
```

### Reset Configuration
```bash
# Start fresh from template
cp .env.example .env
# Edit and add your values
nano .env
```
