## Prevention Measures

### Code Review Checklist

Before merging any PR:
- [ ] No secrets in code, comments, or commit messages
- [ ] Authorization headers properly redacted in logs
- [ ] Error messages don't expose sensitive data
- [ ] Pre-commit hooks pass successfully

### Development Guidelines

1. **Never log sensitive headers**:
   ```python
   # BAD
   logger.info(f"Request headers: {request.headers}")
   
   # GOOD
   safe_headers = {k: v for k, v in request.headers.items() 
                   if k.lower() not in ('authorization', 'cookie', 'x-api-key')}
   logger.info(f"Request headers: {safe_headers}")
   ```

2. **Use environment variables for secrets**:
   - Never hardcode credentials
   - Use `.env` files (gitignored)
   - Use secure secret management in production

3. **Implement secret scanning**:
   - Pre-commit hooks locally
   - CI/CD pipeline checks
   - Regular scans of git history
