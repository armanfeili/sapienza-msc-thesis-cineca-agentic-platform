\chapter{MCP Tool Reference}
\label{app:tool-reference}

This appendix provides a complete reference of the 34 Model Context Protocol (MCP) tools implemented in the Cineca Agentic Platform. Tools are organized into 17 functional categories covering graph operations, security, system management, and data processing.

%------------------------------------------------------------------------------
\section{Tool Architecture Overview}
\label{app:tools:overview}

\subsection{Tool Registration}

All tools use the \texttt{@mcp\_tool} decorator for automatic discovery and registration:

\begin{lstlisting}[language=Python]
from src.mcp.registry import mcp_tool

@mcp_tool(
    name="graph.query",
    description="Execute read-only Cypher queries",
    required_scopes=["graph:read"],
    capabilities=["reads_db"]
)
async def graph_query(payload: GraphQueryPayload) -> GraphQueryResult:
    # Implementation
\end{lstlisting}

\subsection{Common Response Format}

All tools return consistent response structures:

\begin{lstlisting}[language=json]
{
  "ok": true,
  "action": "execute",
  "result": { /* tool-specific data */ },
  "error": null,
  "duration_ms": 150,
  "trace_id": "trace-uuid"
}
\end{lstlisting}

Error responses:

\begin{lstlisting}[language=json]
{
  "ok": false,
  "action": "execute",
  "result": null,
  "error": "Query timeout exceeded",
  "error_code": "QUERY_TIMEOUT",
  "details": { "timeout_ms": 30000 }
}
\end{lstlisting}

\section{Graph Tools}
\label{app:tools:graph}

Graph tools provide comprehensive Memgraph database operations.

\subsection{graph.query}

Execute read-only Cypher queries against Memgraph.

\begin{table}[ht]
\centering
\small
\begin{tabularx}{\textwidth}{lX}
    \hline
    \textbf{Name} & \texttt{graph.query} \\
    \textbf{Description} & Direct Cypher query execution with optional read-only enforcement \\
    \textbf{Required Scopes} & \texttt{tools:basic} \\
    \textbf{Actions} & \texttt{run}, \texttt{explain}, \texttt{profile} \\
    \hline
\end{tabularx}
\end{table}

\textbf{Payload Schema:}
\begin{lstlisting}[language=json]
{
  "action": "run",  // Required: "run" | "explain" | "profile"
  "cypher": "MATCH (p:Person) RETURN p.name LIMIT 10",  // Required: Cypher query
  "params": {},  // Optional: Query parameter dictionary
  "read_only": false,  // Optional: If true, blocks obvious writes (default: false)
  "timeout_ms": 5000,  // Optional: Per-query timeout in milliseconds
  "limit": 1000  // Optional: Soft client-side row cap (slices results)
}
\end{lstlisting}

\textbf{Example Request:}
\begin{lstlisting}[language=json]
{
  "action": "run",
  "cypher": "MATCH (u:User)-[:WORKS_AT]->(i:Institution) RETURN u.name, i.name LIMIT 5",
  "params": {},
  "read_only": true,
  "timeout_ms": 10000
}
\end{lstlisting}

\textbf{Success Response Schema:}
\begin{lstlisting}[language=json]
{
  "ok": true,
  "action": "run",
  "columns": ["u.name", "i.name"],  // Column names from RETURN clause
  "rows": [
    ["John Doe", "CINECA"],
    ["Jane Smith", "Sapienza"]
  ],
  "rowcount": 2,
  "truncated": false,  // True if client-side limit applied
  "read_only": true
}
\end{lstlisting}

\textbf{Error Response Schema:}
\begin{lstlisting}[language=json]
{
  "ok": false,
  "action": "run",
  "error": "Query timeout exceeded",
  "error_code": "QUERY_TIMEOUT",
  "details": {
    "timeout_ms": 10000,
    "query_preview": "MATCH (u:User)..."
  }
}
\end{lstlisting}

\textbf{Common Errors:}
\begin{itemize}
    \item \texttt{QUERY\_TIMEOUT}: Query execution exceeded \texttt{timeout\_ms}
    \item \texttt{SYNTAX\_ERROR}: Invalid Cypher syntax
    \item \texttt{PERMISSION\_DENIED}: Required scope \texttt{tools:basic} not present
\end{itemize}

\textbf{Audit Fields:} Tool invocation logged with correlation ID, tenant ID, user ID, query preview (truncated), execution time, row count.

\subsection{graph.secure\_query}

Natural language to Cypher with safety validation (multi-layer pipeline).

\begin{table}[ht]
\centering
\small
\begin{tabularx}{\textwidth}{lX}
    \hline
    \textbf{Name} & \texttt{graph.secure\_query} \\
    \textbf{Description} & Natural language query with multi-layer safety validation pipeline \\
    \textbf{Required Scopes} & \texttt{graph:read} \\
    \textbf{Actions} & \texttt{query}, \texttt{explain}, \texttt{generate}, \texttt{validate} \\
    \textbf{Safety Checks} & Syntax validation, read-only enforcement, tenant isolation, depth limits, forbidden keywords \\
    \hline
\end{tabularx}
\end{table}

\textbf{Payload Schema:}
\begin{lstlisting}[language=json]
{
  "action": "query",  // Required: "query" | "explain" | "generate" | "validate"
  "nl_query": "Find all users who work at CINECA",  // Required for query/generate
  "cypher": "MATCH (u:User)-[:WORKS_AT]->(i:Institution {name: 'CINECA'}) RETURN u",  // Optional: pre-generated Cypher
  "max_hops": 3,  // Optional: Maximum graph traversal depth (default: 5)
  "limit": 100  // Optional: Result row limit (default: 1000)
}
\end{lstlisting}

\textbf{Example Request:}
\begin{lstlisting}[language=json]
{
  "action": "query",
  "nl_query": "Show me all tasks created by users at Sapienza",
  "max_hops": 2
}
\end{lstlisting}

\textbf{Success Response Schema:}
\begin{lstlisting}[language=json]
{
  "ok": true,
  "action": "query",
  "cypher": "MATCH (u:User)-[:WORKS_AT]->(i:Institution {name: 'Sapienza'})-[:RUNS]->(t:Task) RETURN t LIMIT 100",
  "columns": ["t"],
  "rows": [ /* ... */ ],
  "rowcount": 15,
  "validation": {
    "is_read_only": true,
    "max_hops": 2,
    "forbidden_keywords": []
  }
}
\end{lstlisting}

\textbf{Common Errors:}
\begin{itemize}
    \item \texttt{NL\_TO\_CYPHER\_FAILED}: LLM failed to generate valid Cypher
    \item \texttt{QUERY\_NOT\_READ\_ONLY}: Generated query contains write operations (CREATE, DELETE, SET, REMOVE)
    \item \texttt{MAX\_HOPS\_EXCEEDED}: Query exceeds maximum traversal depth
    \item \texttt{FORBIDDEN\_KEYWORD}: Query contains forbidden keywords (e.g., \texttt{DROP}, \texttt{DETACH DELETE})
    \item \texttt{TENANT\_ISOLATION\_VIOLATION}: Query attempts to access data outside tenant scope
\end{itemize}

\textbf{Safety Pipeline:}
\begin{enumerate}
    \item \textbf{Intent Classification}: Categorizes query intent (CHAT, GRAPH, DANGEROUS)
    \item \textbf{NL-to-Cypher}: Generates Cypher from natural language (LLM-based)
    \item \textbf{Syntax Validation}: Validates Cypher syntax
    \item \textbf{Read-only Check}: Ensures query contains no write operations
    \item \textbf{Forbidden Keywords}: Blocks dangerous operations (DROP, DETACH DELETE)
    \item \textbf{Depth Limit}: Enforces maximum traversal depth
    \item \textbf{Tenant Filtering}: Automatically adds tenant isolation filters
\end{enumerate}

\textbf{Audit Fields:} NL query, generated Cypher, validation results, execution time, row count, tenant ID.

\section{Security and Audit}
\label{app:tools:audit}

All tool invocations are:
\begin{itemize}
    \item \textbf{Scope-validated}: Required scopes checked before execution
    \item \textbf{Tenant-isolated}: Data automatically filtered by tenant
    \item \textbf{PII-scrubbed}: Sensitive data redacted in logs
    \item \textbf{Audit-logged}: All invocations recorded with correlation IDs
    \item \textbf{Rate-limited}: Per-tool rate limits apply
\end{itemize}
