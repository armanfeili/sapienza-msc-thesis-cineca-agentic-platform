\chapter{Configuration Reference}
\label{app:config-reference}

This appendix provides a comprehensive reference of all configuration settings for the Cineca Agentic Platform. Settings are loaded from environment variables using Pydantic Settings, with sensible defaults for local development.

%------------------------------------------------------------------------------
\section{Configuration Loading}
\label{app:config:loading}

Configuration is loaded in the following order of precedence (highest first):
\begin{enumerate}
    \item Environment variables
    \item \texttt{.env} file in project root
    \item Default values in \texttt{src/config.py}
\end{enumerate}

\begin{lstlisting}[language=Python]
from src.config import settings

# Access settings
print(settings.APP_ENV)         # "dev"
print(settings.database_url)    # Property: PostgreSQL URL
\end{lstlisting}

\section{Memgraph Response Builder}
\label{app:config:memgraph-response}

\begin{table}[ht]
\centering
\caption{Memgraph Response Builder Settings}
\label{tab:config-memgraph-response}
\small
\begin{tabularx}{\textwidth}{llX}
    \hline
    \textbf{Variable} & \textbf{Default} & \textbf{Description} \\
    \hline
    \texttt{MEMGRAPH\_RESPONSE\_MODE} & \texttt{llm-best-effort} & Response mode (fallback-only, llm-best-effort, llm-required) \\
    \texttt{MEMGRAPH\_BUILDER\_LLM\_TIMEOUT\_MS} & \texttt{180000} & LLM timeout for response builder (3 min) \\
    \hline
\end{tabularx}
\end{table}

Response modes:
\begin{itemize}
    \item \textbf{fallback-only}: Never call LLM, use deterministic summarizer
    \item \textbf{llm-best-effort}: Try LLM, fall back on timeout (default)
    \item \textbf{llm-required}: LLM required; timeout causes failure
\end{itemize}
