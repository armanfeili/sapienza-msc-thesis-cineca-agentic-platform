\subsubsection{Idempotency Compliance}

Endpoints that create resources support idempotent operations via the \texttt{Idempotency-Key} header:

\begin{itemize}
    \item Duplicate requests with same key return identical responses
    \item Idempotency keys expire after configurable window (default: 24 hours)
    \item Keys are stored in Redis for distributed deduplication
\end{itemize}

\begin{lstlisting}[language=Python,caption={Idempotency test pattern.}]
@pytest.mark.compliance
def test_idempotency_key_deduplication(client, auth_headers):
    """Same idempotency key returns same result."""
    key = str(uuid.uuid4())
    headers = {**auth_headers, "Idempotency-Key": key}
    
    # First request creates resource
    r1 = client.post("/v1/jobs", json=payload, headers=headers)
    assert r1.status_code == 201
    job_id_1 = r1.json()["job_id"]
    
    # Second request returns same resource
    r2 = client.post("/v1/jobs", json=payload, headers=headers)
    assert r2.status_code == 201
    job_id_2 = r2.json()["job_id"]
    
    assert job_id_1 == job_id_2
\end{lstlisting}

\subsubsection{Data Layer Integration}

Database integration is validated for:

\begin{itemize}
    \item \textbf{PostgreSQL}: Repository pattern, transactions, migrations
    \item \textbf{Redis}: Caching, job queues, rate limiting, session state
    \item \textbf{Memgraph}: Graph queries, schema operations, analytics
\end{itemize}

\begin{lstlisting}[language=Python,caption={Database integration test pattern.}]
@pytest.mark.integration
async def test_repository_tenant_isolation(db_session, test_tenant):
    """Verify repository enforces tenant boundaries."""
    repo = AgentRunRepository(db_session)
    
    # Create run in test tenant
    run = await repo.create(tenant_id=test_tenant.id, prompt="test")
    
    # Query from different tenant returns empty
    other_tenant = "other-tenant-id"
    runs = await repo.list_for_tenant(other_tenant)
    assert len(runs) == 0
    
    # Query from same tenant returns the run
    runs = await repo.list_for_tenant(test_tenant.id)
    assert len(runs) == 1
    assert runs[0].id == run.id
\end{lstlisting}
